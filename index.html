FIELD MANUAL

工作台指南

01 / 快速开始

导入音频，或使用内置 DEMO。按空格播放，所有仪表会实时响应。MIDI 只驱动钢琴卷帘可视化，不生成音频，也不会替换当前音轨。

02 / 布局编辑

顶部「编辑」开启后，可直接拖动模块，拖动右下角改变尺寸。开启「吸附对齐」后会吸附到网格、画布边缘、中心线和其他模块边缘。

03 / 视频导出

导出为实时录制，输出画布分辨率与预览一致。MP4 会优先使用浏览器原生 H.264 编码；不支持时再调用本机 FFmpeg 转码。

04 / 计算架构

音频 FFT、节拍与电平分析在音频线程 / CPU 完成；背景等离子支持 WebGL GPU 着色器。示波器、频谱、声场等以 Canvas2D 合成。

FILES / ARCHIVE

存档与路径

把整个工程保存为单个 .neon 文件；不包含音频或视频素材。

工程存档PROJECT

快捷键 Ctrl+S 保存。存档包含布局、主题、动效、信息、动画动作和封面；不包含音轨与视频。关闭软件后可从存档恢复全部改动。

默认存档路径SAVE PATH

留空则使用系统默认位置。EXE 中浏览按钮会打开原生文件夹选择器；视频导出会保存到导出路径。

恢复RECOVERY

编辑会自动写入本机恢复缓存；即使意外关闭，重新打开也会恢复最近一次自动保存。需要长期保存或迁移时，请使用上方“保存存档”。
