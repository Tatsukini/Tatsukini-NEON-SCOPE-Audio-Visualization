# Privacy Policy / 隐私政策

Last updated: 2026-11-04

## English

NEON//SCOPE is a local-first desktop audio and MIDI visualization application.

- Audio, MIDI, background images, project files and exported videos are processed locally on the user's computer.
- The application does not upload media or project content to a remote server.
- The application does not collect telemetry, analytics, advertising identifiers or crash reports.
- The application may request public GitHub metadata (repository information and release information) to display project links. These requests are made directly to GitHub and are subject to GitHub's privacy policy.
- Plugins are third-party code. A plugin may make network requests according to its own behavior. Users should only install plugins from sources they trust. Plugin behavior is not controlled by NEON//SCOPE.
- Settings, layout slots, plugin records and the current project are stored in the local application data directory or the browser's local storage.
- Export paths and save paths are chosen by the user and are never transmitted.

Questions: open an issue at
https://github.com/Tatsukini/Tatsukini-NEON-SCOPE-Audio-Visualization/issues

## 中文

NEON//SCOPE 是一个本地优先的桌面音频与 MIDI 可视化应用。

- 音频、MIDI、背景图片、工程文件和导出视频都在用户本机处理。
- 应用不会把媒体或工程内容上传到远程服务器。
- 应用不收集遥测、统计、广告标识或崩溃报告。
- 应用可能读取公开的 GitHub 仓库与 Release 信息用于展示项目链接；这些请求直接发往 GitHub，受 GitHub 隐私政策约束。
- 插件属于第三方代码，可能按插件自身逻辑发起网络请求。请只安装可信来源的插件；插件行为不由 NEON//SCOPE 控制。
- 设置、排版槽、插件记录和当前工程保存在本机应用数据目录或浏览器本地存储中。
- 导出路径和存档路径由用户自行选择，不会被上传。
