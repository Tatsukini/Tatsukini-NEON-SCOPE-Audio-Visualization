NEON//SCOPE  v1.4.1  (Windows x64)

启动：
  双击 NEON-SCOPE.exe

系统要求：
  - Windows 10 / 11 64 位
  - Microsoft Edge WebView2 Runtime（Windows 10/11 通常已经自带；
    如未安装，程序会给出下载地址）

功能：
  - 导入音频；MIDI 作为钢琴卷帘可视化叠加，不合成音频
  - 支持一次导入多个 MIDI，所有轨道强制合并进同一个 3D 钢琴卷帘模块
  - MIDI 模块专属：轨道 M/S、每轨颜色、单轨深度、音符样式、滚动速度、标题/和弦叠加
  - MIDI 模块总线：统一管理合并后的 MIDI 与每条轨道参数；MIDI 偏移以 10ms 步进，轨道顺序控制 3D 纵深（上远下近），行尾 × 或 Ctrl+Shift+左键删除轨道
  - 内置示例音频 When Rain In My Mind Vol.2 与 6 个配套 MIDI
  - 实时可视化仪表盘，可自由拖动、缩放、吸附对齐模块
  - 模块专属参数：每类模块有独立的显示/样式设置
  - 模块右键快捷菜单：复制、隐藏、独显、居中、图层、删除
  - 主面板与内部小卡片均可独立浮动、关闭、拖动、缩放与恢复
  - RGBA 色盘 + 主题预设，自定义主题色 / 模块色 / 纯色背景（支持透明度）
  - 三套界面风格：NEON GRID / VIDI STUDIO / CATBOT PAPER，可在设置 → 界面切换
  - 明暗模式：跟随主题 / 深色 / 浅色；浅色模式适用于全部主题
  - CATBOT PAPER 会随背景色调和纸张底色，强调色跟随主题色
  - 设置使用独立桌面窗口；设置窗口也会跟随界面缩放（70%–150%）
  - 背景图片实时预览、持久化保存，并支持 Ken Burns / 漂移 / 呼吸 / 节拍动效
  - 动效页可设置片头渐入、片尾渐出与节拍闪光，直接写入导出视频
  - 设置 → 外观提供背景色 / 窗口颜色 / 字符颜色 / 图表颜色四项主题色
  - 图表颜色可跟随背景色、窗口颜色或字符颜色
  - color 动画控制组件背景、窗口标题条、文字和图表四色，支持颜色淡入/淡出；不影响设置页面
  - 信息编辑 / 动画设计面板默认隐藏，可从顶部九宫格面板菜单启用
  - 信息卡可编辑歌曲名、艺术家、作曲、专辑、流派、BPM、曲序、封面
  - 模块库新增「基础信息」：曲绘、歌曲名、作曲、风格、BPM、曲序、采样率、时长
  - 动画设计支持按时间码添加闪白、文字、字幕、染色、淡出动作
  - 动画脚本导入 / 导出：支持 text、mash、color、effect blur、bpm 等时间码格式
  - text / subtitle 使用绝对坐标：X=0、Y=0 位于画面中心；支持文字淡入/淡出时间
  - subtitle 支持换行、行间距、字号、横向/纵向延展和多条字幕自动向上堆叠
  - subtitle 参数分两页（< 1 2 >），第二页含恢复原本设置按钮和确认提示
  - mash 标题卡支持绝对 X/Y 坐标、横向/纵向延展和两页参数
  - Blender 风格动画时间轴：关键帧、动作条拖动/左右修剪、IN/OUT、右键菜单、缩放与吸附
  - 关键帧管理总线：初始隐藏，从面板菜单启用；管理全部动画的关键帧和自动化曲线
  - Intro 开场卡：保留中央信息带，带外画面模糊，读取基础信息与样式
  - 基础信息模块专属设置：主字体颜色、次字体颜色、背景颜色
  - 舞台工具栏可打开独立舞台窗口；目标画面实时镜像
  - 舞台与时间轴之间有可拖动分隔条，可调整两个板块大小
  - 设置 → 外观可切换应用默认字体，并提供恢复默认字体按钮
  - 设置 → 关于提供开发者、许可与版权声明、仓库地址
  - 工程存档保存为单个 .NEON（ZIP 工程包），内含 project.json、动画、音频、MIDI、背景与封面，Ctrl+S 快速保存
  - 设置 → 文件可指定默认存档路径和视频导出路径（原生文件夹选择器）
  - 存档默认保存到本机应用数据目录的 Saves；导出留空则使用 Downloads
  - 快捷键映射窗口：搜索、重绑定、恢复默认
  - 背景图片、GPU / CPU 背景渲染
  - 导出 MP4（H.264 + AAC）或 WebM 视频
  - MP4 默认由 WebView2 原生硬件录制，无需 FFmpeg
  - 导出文件默认保存到设置中的导出路径；留空则使用“下载 / Downloads”

常用快捷键：
  Space 播放/暂停 · F1 快捷键映射 · Ctrl+, 设置
  G 吸附 · E 编辑 · F 专注模式 · Ctrl+D 复制模块 · Delete 删除
  T 时间轴 · K 关键帧总线 · A 添加动作 · F3 独立舞台 · Ctrl+Shift+R 恢复布局
  所有键位均可在 F1 映射表中重新设置（Tab / Esc / 鼠标不可绑定）

设置窗口：
  在 EXE 中点击右下角“设置”会打开一个独立的桌面设置窗口，
  与主窗口分开显示；修改会实时同步回主窗口。关闭设置窗口不会退出程序。

数据位置：
  %LOCALAPPDATA%\NEONScope\
  如果该目录不可写，会自动使用 EXE 同目录下的 NEONScopeData\
  日志文件：neon-scope.log

注意：
  - EXE 未做代码签名，Windows SmartScreen 首次运行可能提示，
    选择“更多信息 → 仍要运行”即可。
  - 导出为实时录制，耗时约等于视频时长；导出时请保持窗口在前台。
  - 4K / 60FPS 对性能要求较高，建议先使用 1080P。
  - 如果系统无法直接录制 MP4，可安装 FFmpeg 并加入 PATH 作为后备转码。
