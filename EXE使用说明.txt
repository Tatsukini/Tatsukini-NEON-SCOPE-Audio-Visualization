NEON//SCOPE  V0.1.4_Alpha_Canary_1114_14  (Windows x64)

启动：
  双击 NEON-SCOPE.exe

系统要求：
  - Windows 10 / 11 64 位
  - Microsoft Edge WebView2 Runtime（Windows 10/11 通常已经自带；
    如未安装，程序会给出下载地址）
  - 内存最低 8 GB；4K 导出建议 16 GB
  - 支持 DirectX 11 的显卡（Intel 第 8 代酷睿核显 / AMD Vega 8 级别起）
  - 磁盘预留 2 GB 以上；视频导出按码率另计（24 Mbps 约 180 MB/分钟）
  - 视频导出可选安装 FFmpeg：加入 PATH，或把 ffmpeg.exe 放在 EXE 同目录 /
    resources\ 下。硬件编码、手动码率 / CRF / 预设、降速导出恢复原速与
    MKV / MOV 封装需要它；未安装时使用 WebView2 原生直录（MP4 受运行时
    支持时可用，否则回退 WebM）
  完整的最低 / 推荐配置见 README「运行环境与硬件下限」。

功能：
  - 导入音频；MIDI 作为钢琴卷帘可视化叠加，不合成音频
  - 默认每次启动都从干净的默认工程开始（内置示例或手动导入），不会恢复
    上次关闭时的排版、动画与音频。如需继续上次工程，请在设置 → 文件中
    勾选“启动时自动开启上一次关闭时留下的自动存档”
  - 支持一次导入多个 MIDI，所有轨道强制合并进同一个 3D 钢琴卷帘模块
  - MIDI 模块专属：轨道 M/S、每轨颜色、单轨深度、音符样式、滚动速度、标题/和弦叠加
  - MIDI O/C 模块：以字符逐轨显示 MIDI 的出现与消失。音符出现时显示
    “+ 轨道名”（增加色，淡入），识别范围内仍有后续音符时只显示轨道名
    （保持色），音符结束且范围内无后续音符时显示“− 轨道名”（减少色，
    淡出），随后消失；短空白并入同一段。可设 X/Y 偏移（相对模块中心）、
    三态颜色与可见度、淡入/淡出时间；宽度达到 760 px 后自动分成左右
    两栏、面积相同，行数与行高按模块高度自动铺满，装不下时末行显示
    “+ N More Track”，暂无音符活动的轨道显示为暗色行名；轨道名后的
    Track N 占位后缀不再显示；文字随模块移动；默认无面板边框，
    除字符外全部透明；开启边框时轨道行排在标题栏下方，不会遮挡首行
  - OSCILLOSCOPE 模块专属设置可切换 自动 / BOTH / L / R 声道显示，
    切换后标题后缀同步更新
  - PEAK SPECTRUM 支持低频 / 中频 / 高频三段颜色，默认取四色方案前三个
  - MIDI 模块总线：统一管理合并后的 MIDI 与每条轨道参数；MIDI 缩放与滚动速度独立，速度默认按 MIDI BPM / 拍号并用音频长度校准，轨道顺序控制 3D 纵深（上远下近），行尾 × 或 Ctrl+Shift+左键删除轨道
  - 内置示例音频 When Rain In My Mind Vol.2 与 6 个配套 MIDI
  - 实时可视化仪表盘，可自由拖动、缩放、吸附对齐模块
  - 模块专属参数：每类模块有独立的显示/样式设置
  - 模块右键快捷菜单：复制、隐藏、独显、居中、图层、删除
  - 主面板与内部小卡片均可独立浮动、关闭、拖动、缩放与恢复
  - RGBA 色盘 + 主题预设，自定义主题色 / 模块色 / 纯色背景均支持透明度
  - 模块外观（背景、标题条、文字、网格）跟随设置页四色主题
  - 三套界面风格：NEON GRID / VIDI STUDIO / CATBOT PAPER，可在设置 → 界面切换
  - 明暗模式：跟随主题 / 深色 / 浅色；浅色模式适用于全部主题
  - CATBOT PAPER 会随背景色调和纸张底色，强调色跟随主题色
  - 设置使用独立桌面窗口；设置窗口也会跟随界面缩放（70%–150%）
  - 背景图片实时预览、持久化保存，并支持 Ken Burns / 漂移 / 呼吸 / 节拍动效
  - 动效页可设置片头渐入、片尾渐出与节拍闪光，直接写入导出视频
  - 设置 → 外观提供背景色 / 窗口颜色 / 字符颜色 / 图表颜色四项主题色
  - 图表颜色可跟随背景色、窗口颜色或字符颜色
  - color 动画控制组件背景、窗口标题条、文字和图表四色，支持颜色淡入/淡出；不影响设置页面
  - 信息编辑 / 动画设计面板默认隐藏，可从顶部九宫格面板菜单启用
  - 信息卡可编辑歌曲名、艺术家、作曲、专辑、流派、BPM、曲序、封面
  - 模块库新增「基础信息」：曲绘、歌曲名、作曲、风格、BPM、曲序、采样率、时长
  - 动画设计支持按时间码添加闪白、文字、字幕、染色、淡出动作
  - 动画脚本导入 / 导出：支持 text、mash、color、effect blur、bpm 等时间码格式
  - text / subtitle 使用绝对坐标：X=0、Y=0 位于画面中心；支持文字淡入/淡出时间
  - subtitle 支持换行、行间距、字号、横向/纵向延展和多条字幕自动向上堆叠
  - subtitle 参数分两页（< 1 2 >），第二页含恢复原本设置按钮和确认提示
  - mash 标题卡支持绝对 X/Y 坐标、横向/纵向延展和两页参数；标题 / 作者 / 来源
    三条文本可分别设置字号（参数第 2 页）
  - Blender 风格动画时间轴：关键帧、动作条拖动/左右修剪、IN/OUT、右键菜单、缩放与吸附
  - 关键帧管理总线：初始隐藏，从面板菜单启用；管理全部动画的关键帧和自动化曲线
  - Intro 开场卡：保留中央信息带，带外画面模糊，读取基础信息与样式
  - 基础信息模块专属设置：主字体颜色、次字体颜色、背景颜色
  - 舞台工具栏可打开独立舞台窗口；目标画面实时镜像
  - 舞台与时间轴之间有可拖动分隔条，可调整两个板块大小
  - 设置 → 外观可切换应用默认字体，并提供恢复默认字体按钮
  - 设置 → 关于提供开发者、许可与版权声明、仓库地址
  - 设置 → 动效可控制预览帧率（10 FPS ~ 无限制）并开关 VSync
  - 设置 → 硬件：自动资源分配、FFT 精度与实时 FPS / 帧耗时 / JS 堆图表；
    预览按画布原生分辨率直绘（最高 1920×1080），导出按所选 720P–4K 渲染
  - 设置侧边栏始终纵向排列；窄窗口收成 56px 图标栏（编号 + 悬停标题）
  - 时间轴：Ctrl+滚轮横向缩放（时间轴轴心），Alt+滚轮纵向缩放（第一轨轴心）
  - 设置 → 文件提供 5 个舞台排版槽，支持导入导出 .NEONMDUL
  - 工程存档保存为单个 .NEON（ZIP 工程包），内含 project.json、动画、音频、MIDI、背景与封面，Ctrl+S 快速保存
  - 设置 → 文件可指定默认存档路径和视频导出路径（原生文件夹选择器）
  - 存档默认保存到本机应用数据目录的 Saves；导出留空则使用 Downloads
  - 关闭主窗口时询问“最小化到托盘 / 直接关闭”，可勾选“不再询问”记住选择；
    最小化到托盘后播放与自动存档继续运行，双击托盘图标可恢复窗口
  - 设置 → 文件可输入自动存档间隔（秒，默认 360）。自动存档会完整打包
    动画、音频、MIDI、排版与背景；连续 5 次检测不到改动时自动暂停，
    下一次改动出现后恢复。在本次运行中首次勾选自动存档时会立即写入一次
  - 选择“直接关闭”或从托盘退出时，程序会先等待当前工程存档写完再关闭，
    因此短时间会话也不会丢掉自动存档
  - 三套界面风格的输入框与下拉框尺寸统一：CATBOT 为直角几何，
    NEON GRID / VIDI STUDIO 为圆角霓虹描边；所有字段共用同一 1px
    描边与等宽字体，浅色模式下统一使用纸面配色
  - 设置窗口中的“保存存档”会交给主窗口执行，确保音频、MIDI 与背景
    一并写入 .NEON；在设置窗口导入存档也会由主窗口完成恢复
  - 关闭窗口触发自动存档时，显示“正在自动存档”进度条与分阶段文案
    （读取工程 → 打包音频与 MIDI → 写入存档），完成或失败后再退出
  - 界面音效：点击、确认、右下角提示弹出 / 成功 / 失败、新增模块、
    滑块按下 / 松开均有程序合成的音效；设置 → 界面可开关并调节音量
  - 左 / 右方向键快退 / 快进 1 秒，长按每秒 5 步；Shift+←/→ 微调模块
    10 px，Ctrl+←/→ 微调 1 px；Delete 直接删除当前选中的动作或模块
  - 快捷键映射窗口：搜索、重绑定、恢复默认
  - 背景图片、GPU / CPU 背景渲染
  - 导出 MP4（H.264 + AAC）或 WebM 视频
  - MP4 在默认设置下优先由 WebView2 原生直录（MediaRecorder）；直录不可用或录制
    降速时改用本机 FFmpeg 转码
  - FFmpeg 转码会在临时目录同时写入录制文件和成片，开始录制前会检查临时盘可用
    空间（约为成片体积的 2 倍 + 512 MB）；空间不足时直接提示所需与可用空间，不再
    录完整段后才失败；转码失败回退 WebM 时会在提示中注明真实原因（如磁盘空间不足）
  - 导出文件默认保存到设置中的导出路径；留空则使用“下载 / Downloads”
  - 帧率保障：录制前会实测刷新率与导出分辨率下的渲染吞吐，必要时自动降速录制，
    再由 FFmpeg 还原原速封装，保证导出帧率与设定一致。此模式需要 FFmpeg，
    导出耗时约为视频时长的 1–2 倍（含转码）
  - 高级导出新增硬件编码：自动（优先硬件）/ 软件 / NVIDIA NVENC / AMD AMF /
    Intel QSV；启动时自动探测本机可用的硬件编码器，不可用时回退软件编码，
    VP8 / VP9 仅支持软件编码
  - 导出进度的中央区域会实时显示 FFmpeg 日志；直接录制模式下显示录制状态
  - 降速导出时成片音轨直接取自原始音频文件（封装前自动上传到本地临时目录），
    不再使用被放慢的录制音轨，因此不会变调或发闷；音量滑块不影响成片电平
  - 取消导出会中止上传并终止 FFmpeg 转码，录制阶段与封装阶段都能立即停止
  - 导出按设定帧率采样画布，不再因帧率节流产生大量重复帧

常用快捷键：
  Space 播放/暂停 · F1 快捷键映射 · Ctrl+, 设置
  G 吸附 · E 编辑 · F 专注模式 · Ctrl+D 复制模块 · Delete 删除
  T 时间轴 · K 关键帧总线 · A 添加动作 · F3 独立舞台 · Ctrl+Shift+R 恢复布局
  所有键位均可在 F1 映射表中重新设置（Tab / Esc / 鼠标不可绑定）

设置窗口：
  在 EXE 中点击右下角“设置”会打开一个独立的桌面设置窗口，
  与主窗口分开显示；修改会实时同步回主窗口。关闭设置窗口不会退出程序。

数据位置：
  %LOCALAPPDATA%\NEONScope\
  如果该目录不可写，会自动使用 EXE 同目录下的 NEONScopeData\
  日志文件：neon-scope.log

注意：
  - EXE 未做代码签名，Windows SmartScreen 首次运行可能提示，
    选择“更多信息 → 仍要运行”即可。
  - 导出时请保持窗口在前台；窗口切到后台会暂停画布出帧，程序会提示并中止导出。
  - 为保证帧率可能会降速录制，再由 FFmpeg 还原原速（需要 FFmpeg）。
  - 4K / 60FPS 对性能要求较高，建议先使用 1080P。
  - 启用降速录制、硬件编码或手动指定码率 / 预设 / CRF 时，需要系统已安装
    FFmpeg 并加入 PATH，否则会回退为原生实时录制。
